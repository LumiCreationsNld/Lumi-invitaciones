# Pruebas del Sprint 0

1. Abre el proyecto con Live Server.
2. Confirma que el fondo cubra toda la pantalla antes y después de abrir.
3. Pulsa **Abrir Invitación** y verifica que la música comience.
4. Prueba pausar y reanudar con el botón flotante.
5. Confirma que el nombre use Futurino.
6. Desplázate hasta el final y comprueba que el fondo no salte ni se corte.
7. Revisa la consola: no debe aparecer el error de volumen ni el 404 de favicon.
