# Lumi Header — Alpha 7

## Objetivo

Dejar el encabezado visualmente integrado y estable en móvil y escritorio.

## Cambios

- Nombre al 80% del ancho interno del marco.
- Nombre siempre en una sola línea.
- Tipografía adaptable al ancho real del componente.
- Menor separación entre el nombre y la celebración.
- Orden vertical: `Cumple` → número → `Años`.
- Ajustes de precisión en márgenes, interlineado y separación de letras.

## Pruebas

1. Abrir con Live Server.
2. Probar ancho móvil y escritorio.
3. Confirmar que `ELIETTE` no se divide en dos líneas.
4. Confirmar que el bloque completo se percibe unido.
5. Confirmar que la consola permanece limpia.
