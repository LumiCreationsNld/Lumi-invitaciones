# Estructura V4

- `js/core`: núcleo sin conocimiento del tema.
- `js/services`: recursos, tema, audio, acciones y contador.
- `js/components`: piezas visibles.
- `js/templates`: orden de componentes.
- `css`: una sola cascada, cargada de general a específico.
- `assets/themes/<tema>`: recursos exclusivos de cada temática.

Regla principal: una responsabilidad por archivo y ningún nombre duplicado dentro de la configuración.
