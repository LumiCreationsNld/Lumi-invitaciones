# Sprint 1 — Foundation

Esta etapa crea el vocabulario visual de LUMI Design System. Los componentes todavía conservan su apariencia Alpha 3, pero ahora todos pueden migrarse gradualmente hacia una única fuente de verdad.

## Archivos nuevos

- `css/base/tokens.css`
- `css/base/typography.css`

## Familias tipográficas

- Futurino: nombres y edades protagonistas.
- Fredoka: títulos, intro y botones.
- Poppins: información y texto de lectura.

## Escala de espaciado

4, 8, 12, 16, 24, 32, 48 y 64 px.

## Regla de migración

A partir de Alpha 4, los componentes nuevos deben usar variables con prefijo `--lumi-`. Los alias antiguos existen solamente para evitar que la migración rompa la versión estable.
